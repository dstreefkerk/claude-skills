# Microsoft Stream / SharePoint Transcript API Endpoints

## Base URL

All endpoints are relative to the SharePoint site root:

```text
https://{tenant}-my.sharepoint.com
```

## Working Endpoints

### Get item metadata

```text
GET /_api/v2.1/drives/{driveId}/items/{itemId}
Accept: application/json
Auth: Cookie-based (credentials: 'include')
```

Returns full item metadata including `@content.downloadUrl`, `name`, `media`, `video` properties.

### Get media metadata

```text
GET /_api/v2.1/drives/{driveId}/items/{itemId}/media
Accept: application/json
Auth: Cookie-based
```

Returns recording times, visibility settings, viewpoint permissions.

### List transcripts

```text
GET /_api/v2.1/drives/{driveId}/items/{itemId}/media/transcripts
Accept: application/json
Auth: Cookie-based
```

Returns array of transcript objects with fields:

| Field | Description |
|-------|-------------|
| `id` | Transcript UUID (used as `transcriptId` in content endpoint) |
| `displayName` | Transcript file name |
| `cTag` | Content tag for caching |
| `size` | Size in bytes |
| `languageTag` | Language code (e.g., `en-US`) |
| `transcriptType` | Type (e.g., `subtitle`) |
| `isVisible` | Whether transcript is visible to users |
| `isAutoGenerated` | Whether AI-generated |
| `isDefault` | Whether this is the default transcript |
| `temporaryDownloadUrl` | Pre-authenticated download URL (no cookies needed, time-limited) |
| `source` | Origin (e.g., `microsoft teams`) |

### Get transcript content (plaintext)

```text
GET /_api/v2.1/drives/{driveId}/items/{itemId}/media/transcripts/{transcriptId}/content
Accept: */*
Auth: Cookie-based
```

Returns **plaintext WebVTT** with `Content-Type: text/vtt`. This is the key endpoint.

### Get transcript via temporaryDownloadUrl

```text
GET {temporaryDownloadUrl}
Auth: None (tempauth token embedded in URL)
```

Returns plaintext WebVTT. URL expires after a short period. Obtained from the list transcripts response.

### Resolve file path to driveItem (sharing API)

```text
GET /_api/v2.1/shares/u!{base64EncodedUrl}/driveItem
Accept: application/json
Auth: Cookie-based
```

The `{base64EncodedUrl}` is constructed by:

1. Taking the full file URL: `https://{tenant}-my.sharepoint.com{filePath}`
2. Base64-encoding it
3. Replacing `=` with empty, `/` with `_`, `+` with `-`
4. Prepending `u!`

Returns a driveItem object with `id` (itemId) and `parentReference.driveId`.

## Endpoints to Avoid

### CDN-cached transcript endpoint (encrypted)

```text
GET /_api_cached/v2.1/drives/{driveId}/items/{itemId}/cdnmedia/transcripts?kid={keyId}&transcriptkey={transcriptId}&...
Auth: Cookies + x-authorization header (Bearer JWT)
```

Returns **AES-encrypted binary data** despite `Content-Type: text/vtt` header. Requires a client-side decryption key that is derived in the browser JavaScript. Do not use this endpoint.

## Authentication Notes

- The `_api/v2.1/` (non-cached) endpoints work with standard SharePoint cookie authentication
- Use `credentials: 'include'` in fetch calls from an authenticated browser session
- The `_api_cached/` endpoints require an additional `x-authorization` Bearer JWT header
- `temporaryDownloadUrl` values contain embedded `tempauth` tokens and require no additional auth
